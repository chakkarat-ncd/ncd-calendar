# ปฏิทินยอดนัด คลินิก NCD — โรงพยาบาลจักราช

เว็บแอปดูยอดนัดล่วงหน้าของคลินิก NCD ทั้ง 9 คลินิก เทียบกับเพดาน 80 นัดต่อวัน
ทุกจอเห็นยอดชุดเดียวกันเพราะเก็บยอดไว้บน Supabase

## ข้อมูลผู้ป่วยไม่ออกจากเครื่อง

ไฟล์ที่ export จาก HosXP มีชื่อผู้ป่วยและ HN — ไฟล์นั้น **ไม่เคยถูกส่งขึ้นเซิร์ฟเวอร์**
เบราว์เซอร์อ่านไฟล์เอง ทิ้งคอลัมน์อื่นทั้งหมดตั้งแต่ตอนอ่าน เหลือแค่ชื่อคลินิกกับวันที่นัด
แล้วนับยอดเสร็จจึงส่งขึ้นระบบเฉพาะ `{ วันที่, ชื่อคลินิก, จำนวน }`

เส้นทางของข้อมูลอยู่ที่ [src/lib/excel.ts](src/lib/excel.ts) → [src/lib/counts.ts](src/lib/counts.ts) → [src/lib/supabase.ts](src/lib/supabase.ts)

## เริ่มใช้งาน

```bash
npm install
```

ใส่ค่าเชื่อมต่อในไฟล์ `.env` หาค่าได้ที่
Supabase Dashboard → Project Settings → API

```
VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxxxxxx
```

`.env` อยู่ใน `.gitignore` แล้ว จะไม่ถูก commit

```bash
npm run dev      # เปิดที่ http://localhost:5173
npm run build    # สร้างไฟล์สำหรับขึ้นเซิร์ฟเวอร์ที่ dist/
npm run preview  # ลองเปิดไฟล์ที่ build แล้ว
```

## หน้าในระบบ

| หน้า | ใครใช้ | ทำอะไร |
|---|---|---|
| `/` | ทุกคน ไม่ต้องล็อกอิน | ดูปฏิทินยอดนัด สรุป 4 ตัวเลข และตารางวันที่ยังรับนัดได้ |
| `/upload` | คนที่มีรหัสอัปโหลด | ส่งไฟล์นัดจาก HosXP ขึ้นระบบ แทนที่ยอดเดิมทั้งหมด |
| `/local` | ทุกคน | เปิดไฟล์ดูในเครื่องอย่างเดียว ไม่แตะฐานข้อมูล ใช้เป็นทางสำรอง |

หน้าปฏิทินโหลดข้อมูลใหม่เองทุก 5 นาที และทุกครั้งที่กลับมาที่แท็บนี้

## เกณฑ์สี

| สี | ยอดนัดต่อวัน | ความหมาย |
|---|---|---|
| เทา | 0 | ไม่มีนัด |
| เขียว | 1–60 | ยังรับได้สบาย |
| เหลือง | 61–80 | ใกล้เต็ม |
| แดง | มากกว่า 80 | เกินเพดาน |

## คลินิกที่นับ

เบาหวาน · ความดันเลือดสูง · ชะลอไตเสื่อม · คลินิก วาร์ฟาริน · คลีนิก CVA · MED NCD · IMC · NCD Clinic · คลินิค Palliative care

ไฟล์จาก HosXP มีทุกคลินิกของโรงพยาบาล ระบบจะติ๊ก 9 คลินิกนี้ให้อัตโนมัติ
ถ้าชื่อคลินิกใน HosXP เปลี่ยนไป จะขึ้นเตือนว่าหาคลินิกไหนไม่เจอ และติ๊กชื่อใหม่เองได้จากหน้าอัปโหลด
รายชื่ออยู่ที่ `NCD_CLINICS` ใน [src/lib/constants.ts](src/lib/constants.ts)

## ไฟล์นัดจาก HosXP

ต้องมีคอลัมน์ชื่อ **คลินิก** และ **วันที่นัด** (มีช่องว่างเกินได้ ระบบตัดให้)
ถ้าหาไม่เจอ ระบบจะบอกว่าขาดคอลัมน์ไหนพร้อมแสดงรายชื่อคอลัมน์ที่มีจริงในไฟล์

วันที่รองรับทั้ง Excel serial, ค่าวันที่จริง, `5/9/2568`, `2568-09-05` และแบบ ค.ศ.
ถ้าปีมากกว่า 2400 ระบบลบ 543 ให้เอง

## ฐานข้อมูล

สร้างไว้แล้วบน Supabase — โค้ดฝั่งนี้ไม่แก้ schema

- `appointment_counts (appt_date, clinic_name, cnt)` — anon อ่านได้อย่างเดียว
- `upload_log (id, uploaded_at, uploaded_by, day_count, total_appointments, date_from, date_to)` — anon อ่านได้อย่างเดียว
- `replace_appointment_counts(p_key, p_uploader, p_rows)` — ตรวจรหัสอัปโหลดเอง
  ลบยอดตั้งแต่วันนี้เป็นต้นไปทั้งหมด แล้วใส่ชุดใหม่ในทรานแซกชันเดียว

การเขียนข้อมูลผ่าน rpc ตัวนี้ตัวเดียว รหัสอัปโหลดไม่เคยถูกเก็บในเบราว์เซอร์

## ขึ้น Vercel

1. Import โปรเจกต์นี้ — Vercel ตรวจเจอ Vite เอง
2. ใส่ `VITE_SUPABASE_URL` และ `VITE_SUPABASE_PUBLISHABLE_KEY` ที่ Settings → Environment Variables
3. Deploy

[vercel.json](vercel.json) ตั้ง rewrite ให้ทุก path ชี้ไป `index.html` แล้ว
เพื่อให้เปิด `/upload` และ `/local` ตรง ๆ ได้โดยไม่ 404

ถ้าลืมใส่ environment variable หน้าเว็บจะบอกตรง ๆ ว่าขาดค่าตัวไหน
พร้อมปุ่มไปโหมดดูจากไฟล์ ไม่ใช่จอขาว

## ต้นแบบ

[prototype.html.html](prototype.html.html) คือไฟล์ HTML ไฟล์เดียวที่ใช้งานจริงมาก่อน
เก็บไว้อ้างอิง ตรรกะการอ่านไฟล์ การกรองคลินิก เกณฑ์สี และหน้าตา ยกมาจากไฟล์นี้

ต่างจากต้นแบบสามจุด: ปฏิทินเริ่มวันจันทร์แทนวันอาทิตย์,
ป้ายในแถบสรุปบอกช่วงวันจริงแทนที่จะเขียนว่า 90 วันตายตัว,
และวันที่เพี้ยนที่อ่านมาจากเซลล์ที่ไม่ใช่วันที่จะถูกตัดทิ้งแทนที่จะกลายเป็นปี ค.ศ. หลักแสน
